# HealthQuest

Личный дашборд здоровья в стиле RPG: связи между проблемами, карта тела, лечение, план и реестр документов.

**Сайт:** https://pavelkostyukov.github.io/healthquest/

## Файлы

- `index.html`: сам дашборд, одна страница без сборки.
- `sources/health.md`: медкарта и план (обновлено 20.11.2026).
- `sources/medical_documents.md`: реестр медицинских документов и анализов (обновлено 21.11.2026).

## Как обновить

Замени `index.html` новой версией и закоммить в `main`. GitHub Pages обновится за минуту-две.
